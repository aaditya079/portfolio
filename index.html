01 / Featured project

ImgSeek

An offline-first screenshot search engine for people who keep too much useful information in images.

Built with native WinRT OCR and SQLite to index local screenshots, query them by their visible text, and generate a clean local HTML lightbox gallery. It has indexed 10,000+ images while keeping retrieval under 1.5 seconds and external APIs out of the critical path.

03 / Working principles

Good engineering has a point of view.

01

Local when it matters

Offline-first is not a limitation by default. It can mean better privacy, lower latency, and a tool that remains useful in imperfect environments.

02

Proof over adjectives

I try to express engineering decisions through retrieval time, dataset size, failure modes, and other signals that make the work easier to evaluate.

03

Interfaces for the next person

Readable output, focused dashboards, and a clean handoff are part of the system. A useful tool should explain itself without a tour guide.
