An immersive, cyberpunk/anime-inspired developer portfolio and interactive showcase built by **Aaditya Srinivasan (fw_aadi)**.

---

## ✨ Highlights & Features

- 🎭 **Dual Ambient Modes:** Toggle between **Café Crossroads** (chill lofi mood) and **Bomb Devil** (high-intensity overdrive mode) with seamless background video looping.
- 🎵 **Integrated Audio Deck:** Custom interactive audio player streaming background soundtracks (`Jane Doe`).
- 📂 **Selected Systems Showcase:** Highlighting projects across multi-agent AI, offline search, systems programming, and high-performance native desktop clients.
- 📄 **Integrated Resume Viewer:** Quick access and direct download for updated engineering credentials.
- ⚡ **Zero-Framework Lightweight Architecture:** Pure, performant semantic HTML5, modern CSS3 animations, and vanilla JavaScript.

---

## 🛠️ Tech Stack

- **Markup & Styling:** Semantic HTML5, CSS3 Custom Properties, Responsive Layouts
- **Scripting:** Vanilla JavaScript (ES6+), Web Audio API
- **Deployment:** GitHub Pages
